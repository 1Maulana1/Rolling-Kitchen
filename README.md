# Rolling-Kitchen
🚚🍳 Rolling Kitchen adalah game 2D single-player bergenre cooking &amp; management. Jalankan food truck-mu sendiri: terima pesanan pelanggan, masak dan sajikan hidangan dengan cepat, jaga kepuasan pelanggan, dan kembangkan bisnis dapur kelilingmu. Dikerjakan sebagai proyek tim oleh mahasiswa Informatika.
